# 使用 HeyMelody for Windows

本页面向客户端用户，说明当前 0.9.2 的常用操作。本轮为 Windows 本地构建，尚未发布到 GitHub。下载入口见[项目 README](../README.md)，逐版本变化见[版本记录](history/release-notes.md)。

## 首次连接

1. 在 Windows 蓝牙设置中配对并连接耳机。
2. 完整解压发布包，运行 `Start-HeyMelody.cmd`；启动器选择包内对应架构。若取得本地生成的 Inno Setup 安装器，也可安装后从开始菜单启动。
3. 从主界面打开设备管理器，选中要管理的设备并保存名单。
4. 返回主界面选择耳机，等待状态读取完成。可用设置由欢律配置、耳机能力、当前状态和已实现协议决定。

普通发布包包含主界面、共享托盘后台、设备管理器、耳塞贴合度测试和黄金听感向导，并自带 .NET 运行时。请保留整个目录，单独复制 `HeyMelody.exe` 不能替代完整安装。

Inno Setup 安装器只为当前用户安装，默认目录为 `%LOCALAPPDATA%\Programs\HeyMelody`，可在安装目录页自定义，无需管理员权限。最后一页的“创建桌面快捷方式”首次默认勾选，以后保留上次选择，包括取消勾选。开始菜单仅添加一个 HeyMelody 主程序入口，不创建子目录。卸载请使用 Windows“应用和功能”，用户设置和已下载资源会保留，只清理安装清单列出的程序文件。安装或更新前关闭所有界面并从托盘退出后台；检测到程序仍在运行时，安装器会提示退出。安装 EXE 由独立本地脚本生成，GitHub Actions 继续构建目录和 ZIP，下载方式以实际发布内容为准，见[安装器说明](installer.md)。

设备添加键“+”短按打开 Windows 蓝牙设置；长按两秒显示临时 Demo 设备。没有已配置设备时，可直接运行 `Start-3D-Demo.cmd` 离线体验。Demo 使用模拟状态，设置不发送到真实耳机，关闭主窗口后移除。

## 状态、后台与更新

页头状态点以绿、黄、灰表示已连接、正在连接或写入、未连接。离线时显示上次连接时间及已保存的设置控件，控件可展开查看，但不能操作设备；重新连接后读取当前能力与设置。第一次有效连接之前没有历史功能缓存。

耳机状态提示位于连接状态右侧。长提示可悬停查看；通知订阅不完整与读取失败有不同提示，部分通知不可用时仍可手动刷新。

固件条件未满足或尚无法确认时，只在主界面右上角显示提醒，不阻止连接或单凭固件版本禁用设置。若显示“编码查询不可用”，其他已核实功能仍可使用；未知的编码或设备状态保持未知。显式重连会重新尝试读取，提醒不表示该固件已完成实机验证。

自 0.9.1 起页头只保留应用设置按钮。双击底栏中当前选中的耳机卡片刷新状态；三击断开控制连接，1 秒后重新连接。键盘可按 F5 刷新、Shift+F5 重新连接。重新连接只重建控制连接并重新读取状态，不会重发任何设置；均衡器有未保存的调整时会先确认。

关闭主窗口后后台继续运行。单击托盘图标打开主界面，右键菜单可重新打开界面或完全退出；托盘提示显示当前已连接的耳机。更新时先关闭旧主窗口，再从托盘退出旧后台，然后使用完整的新包；只替换界面可能仍连到旧后台。当前没有登录自启或独立开盖弹窗。

所有窗口关闭约 10 秒后，任务管理器会把托盘和后台子进程显示为“效率模式”（低优先级、省电运行），打开任一窗口后立即恢复。这是预期行为，不是故障，也不需要手动更改；后台仍保持监听。名单中没有已配对的耳机时，后台不扫描蓝牙广播，允许或配对耳机后会自动恢复。该行为为 review/0.9.9 分支新增，Windows 上的显示与响应仍在验证，见[后台能耗](research/backend-energy.md)。

## 常用设置

右侧设置按“声音”（降噪、均衡器、音频体验）、“听感与佩戴”（黄金听感、贴合度测试）和“设备”（耳机设置、操控、设备信息、操作记录）分组。窗口较窄时图片与设置仍左右排列，宽屏上两者会适当放大。

| 操作 | 使用方式 |
| --- | --- |
| 降噪与通透 | 选择圆形模式按钮；有细分选项的型号在下方调整档位 |
| 均衡器 | 选择内置预设，或编辑自定义 EQ 后“保存并启用”；频段和可保存数量随型号变化 |
| BassWave™ | 支持的型号在均衡器卡片下方的设置行调整动态低音开关与强度 |
| 游戏、Hi-Res、空间音效 | 操作耳机实际开放的开关；自 0.8.13 起隐藏游戏音效类型选项 |
| 设备信息 | 展开查看完整固件与产品信息，使用复制按钮收集问题反馈所需信息 |
| 操作记录 | 展开后在只读文本框中查看本次运行保留的最近 80 条记录，可滚动、选中与复制 |
| 应用设置 | 主题选择后立即预览，取消则恢复；连接或切换耳机期间，资源与设备相关项暂不可改 |
| 使用 Basic Render 兼容模式 | 默认关闭，普通界面使用默认 GPU；Inno Setup 安装器识别到特定旧骁龙 GPU 时会启用，范围见[安装器说明](installer.md)。显示异常时也可在应用设置的“外观”中开启。保存后关闭并重开所有界面窗口，托盘后台无需退出；此选项可能降低流畅度，与三维模型 API 独立 |
| 3D模型渲染API | 下拉选择 Vulkan 或 OpenGL，默认 Vulkan；若存在渲染问题，请尝试切换到 OpenGL。保存后立即生效，取消不改变设置 |
| 3D模型渲染帧率 | 滑块吸附到 30帧、60帧、无限制三档，默认无限制；保存后立即生效，取消不改变设置。无限制档不设额外上限，实际帧率受窗口刷新与渲染耗时限制 |

Enco X2、Enco X3 选择通透后，可使用下方“强化人声”开关，其作用是“弱化环境声的同时突出人声”。“未确认”表示通透子状态尚未读取；状态回填不会自动设置，连接和能力允许时仍可明确点击开关。Enco Free2、Free2i、Air2 Pro、R Pro 的对应功能是独立的“聆听”主模式，用于“减弱周围噪音基础上保留人声/广播声”。具体选项以欢律配置和耳机能力为准，名称与控件依据见[研究说明](research/anc-transparency-controls.md)。

耳机的 Hi-Res/codec 状态不等于 Windows 音频驱动实际使用的采样率、传输码率或无损状态。项目不因显示某个开关就承诺这些链路结果。

## 贴合度与黄金听感

耳塞贴合度测试要求双耳正确佩戴，结果分别显示左右耳状态和调整建议。

黄金听感在独立向导中进行耳道扫描与左右耳听音测试。按当前步骤提示调节音量，再选择“下一步”；可返回、取消或停止。完成后查看左右耳六轴雷达图，点击“增强前／增强后”比较内置音乐，再命名、保存并启用。再次点击正在播放的试听按钮可暂停。

主界面的黄金听感下拉框选择本机保存或耳机当前完整读回的方案。没有方案时先打开设置向导；耳机不支持、设备拒绝、断连或流程被取消时，以界面提示为准。校准组件使用同一后台连接，测试期间部分冲突设置暂不可用。

## 资源与本地数据

客户端仅使用欢律配置与美术，默认开启在线资源。设置提供在线资源开关、欢律请求密钥和重新下载；密钥留空时使用预置值。保存资源设置不会丢弃尚未保存的 EQ 草稿。

关闭在线资源后停止资源请求，已下载且验证有效的资源仍可使用。需要重新获取时，使用设置中的“重新下载在线资源”；下载和校验失败会保留现有资源。预装资源不因在线更新清理。

设备选择、离线功能状态、外观提示及应用设置保存在用户本地。自定义请求密钥和缓存加密密钥以本地 JSON 明文保存，不应把设置文件或密钥直接贴到公开问题中。项目不依赖原始 APK 或研究档案运行。

升级后保留原欢律密钥、在线开关、缓存加密密钥及有效欢律缓存；只迁移旧欢律展示快照，不使用已退出支持来源的快照或资源缓存。原 Windows 配对、设备选择和听感历史保留；欢律配置未覆盖的型号不能获得控制权限。更新时须退出旧后台并使用完整的新客户端，通信版本不兼容时会给出提示。

## 诊断日志

需要复现连接、校准或显卡问题时，在“应用设置 → 故障诊断 → 诊断日志”选择组件，打开“在下次启动程序时记录日志”并保存，再从托盘退出后台后重新启动。首次默认全选五个组件；蓝牙通信由 `HeyMelody.Host` 记录。该设置只启用一次后台运行周期，后台再次启动时恢复关闭。

“打开日志目录”按钮始终可用，打开 `%LOCALAPPDATA%\HeyMelody\logs`；不存在时创建，不会开启日志或后台。复现后正常退出托盘后台，再收集本轮文件夹。日志包含完整通信、设备标识、本地路径和异常，分享前自行检查；旧记录不会自动删除。完整说明见[诊断日志](diagnostics.md)。

## 常见问题

如果界面完全透明或黑屏，无法打开设置，先关闭所有界面窗口，再打开 `%LOCALAPPDATA%\HeyMelody\preferences.json`，将 `uiBasicRenderMode` 设为 JSON 布尔值 `true`，保留其他字段，然后重新打开界面。文件不存在时可创建内容为 `{"uiBasicRenderMode":true}` 的文件。只有 JSON 布尔值 `true` 启用兼容模式；关闭兼容模式后重新打开界面即可恢复默认 GPU。不要在校准尚未结束时关闭其窗口来切换渲染模式。

| 现象 | 检查方式 |
| --- | --- |
| 找不到或连不上耳机 | 先确认 Windows 已配对、连接，并在设备管理器保存了该设备；确认正在使用完整发布目录 |
| 耳机控制连接暂不可用 | 双击底栏当前耳机刷新，必要时三击重连；反馈时附详细提示中的 SPP 服务、查询命令号、格式失败原因或 Windows 错误码，以及耳机固件和配置内容版本。查询命令号表示当时等待的请求。Air4 Pro 核查及修复范围见[研究说明](research/enco-air4-pro-control.md) |
| 型号有图片，但缺少设置 | 图片识别不代表控制协议已适配；查看欢律配置覆盖、实际回报与[设备支持说明](research/oppo-device-support.md)，固件提醒本身不会开放未知能力 |
| 关闭窗口后仍有托盘图标 | 这是共享后台的正常运行方式；完全退出请选择托盘菜单“退出” |
| 任务管理器里后台显示“效率模式” | 所有窗口关闭约 10 秒后自动进入，打开窗口即恢复，是预期行为；只有托盘和后台子进程如此，界面窗口保持正常优先级 |
| 更新后仍像旧版本或提示版本不一致 | 退出旧托盘后台，重新启动完整的新版本包 |
| 离线仍显示旧设置 | 这是缓存展示，不能写入耳机；耳机连接后会自动读取，也可双击底栏中的当前耳机刷新 |
| 三维模型显示异常 | 在设置的“3D模型渲染API”下拉框选择 OpenGL；无法渲染时显示静态外观，没有同款图片的演示显示通用耳机图标。Vulkan 失败不会自动切换模式；细节见[模型渲染](model-rendering.md) |
| 三维模型较耗电或想确认帧率 | 在设置中把“3D模型渲染帧率”改为 60 或 30 帧；按 Ctrl+Shift+F12 可显示帧率与帧时间叠加层 |
| 中文字形看起来像日文 | 0.9.0 起界面固定使用微软雅黑 UI 和简体中文回退；托盘提示与任务栏标题由 Windows 绘制，不受此设置影响 |

仍有问题时，请在 [Issues](https://github.com/swift-lee/heymelody-windows/issues) 提供应用版本、Windows 版本、架构、耳机型号和固件、配置内容版本、操作步骤及实际提示。不要公开蓝牙地址、密钥或完整设备快照。
