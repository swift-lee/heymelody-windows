# HeyMelody macOS

支持 Apple silicon Mac（M1 或更新芯片），最低 macOS 15。此包自带 .NET 10，无需安装开发工具。Intel Mac 暂不支持。

打开 DMG 后，把 **HeyMelody.app** 拖到 **Applications（应用程序）**，再从应用程序目录启动。保留整个 App，不要单独移动内部后台或窗口组件。

这个构建使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开若被系统阻止，请在“系统设置 → 隐私与安全性”查看对应的“仍要打开”选项。安装来源与文件摘要应与提供方一致。

先通过 macOS 蓝牙设置配对耳机，再在 HeyMelody 中选择设备。允许系统询问的蓝牙访问权限。关闭主窗口后菜单栏后台继续运行；通过菜单栏图标退出可结束整个应用。

本轮已完成的离线、界面和构建检查不能证明蓝牙真机效果。实际耳机连接、控制、校准和休眠恢复留待后续真机验证。

更新时先从菜单栏退出 HeyMelody，再替换应用程序中的 App。资源来源、NuGet 与原生组件许可见 App 内 `Contents/Resources/` 的说明和许可目录。
