# Current resource provenance

This experimental branch renders models with upstream Google Filament commit ea31afeaf66339e7414aa648aa76c7e61adbde28, through an independently built ABI-2 C bridge. Windows defaults to Vulkan; the compatibility-mode setting explicitly selects OpenGL. Both backends and their same-version material archive are included. The short-lived native probe tests backend initialization before in-process rendering; it is not a separate rendering service. Runtime identity, compiled backends, default backend, probe, material hashes and linked-component licenses are recorded in schema-2 filament-runtime.json. Vulkan is dynamically loaded; no GPU ICD or Vulkan SDK is redistributed. Linked Vulkan dependencies include BlueVK, Vulkan Memory Allocator, smol-v and SPIRV-Headers. Windows x64 has actual runtime verification; Windows ARM64 is cross-built and statically verified. macOS Metal and Linux Vulkan/EGL builds are prepared separately. The inspected HeyMelody 17.6.5 and ColorOS Wireless Earphones 17.6.3 samples use OPLUS VFX ModelViewer 1.3.8 wrappers around Filament/gltfio; that wrapper version does not identify an exact upstream revision. No Android VFX SDK or JNI binary is redistributed. The historical release provenance below retains its original renderer and architecture scope.

The retained 0.6.2 and 0.6.3 static receipts, `HeyMelody_Windows_0.6.2_STATIC-VALIDATION.json` and `HeyMelody_Windows_0.6.3_STATIC-VALIDATION.json` beside the release packages, verified those releases' executable and managed DLL hashes, dependencies, runtimes and notices; neither validates 0.6.4 or 0.6.5. The existing 0.6.4 package has its own `HeyMelody_Windows_0.6.4_STATIC-VALIDATION.json` report, which does not validate the subsequent X4 artwork/view changes. The 0.6.5 package has its own version-matched `HeyMelody_Windows_0.6.5_STATIC-VALIDATION.json` report. Static PE, dependency, self-contained runtime, icon and notice checks prove packaging properties; they do not prove Bluetooth behavior on a particular machine or native ARM64 execution.
